# Contributing

Keep contributions focused on the public runtime, sandbox, tests, or
documentation. Do not add private project context, deployment configuration,
credentials, unpublished assets, local machine paths, or links to restricted
workspaces.

## Setup

```sh
npm ci
npm test
```

## Pull requests

Describe the affected public API or content behavior, include focused tests,
and call out any lifecycle, GPU-memory, asset-rights, or compatibility impact.
Generated catalogs and integrity receipts must be regenerated from their public
inputs rather than edited by hand.

Contributing does not grant or expand permission to use Axie or third-party
materials. All contributions remain subject to [RIGHTS.md](./RIGHTS.md).
